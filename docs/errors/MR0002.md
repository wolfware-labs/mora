# MR0002: a `#` directive other than `#region` or `#endregion`

A line starts with a preprocessor directive such as `#if`, `#define`, `#pragma` or `#nullable`. Mora has no preprocessor: the compiler sees every line of a file, so code cannot change depending on symbols defined elsewhere. `#region` and `#endregion` are accepted and ignored.

To compile code only for some builds, put the `[Cfg]` attribute on the declaration or statement, as in `[Cfg(Debug = true)] Log(x);`. Silence a warning with `[Allow("MRnnnn")]`. Nullable checking is always on, so a `#nullable` line can simply go.

## Failing example

```mora
// error: MR0002
#nullable enable
Console.WriteLine("ready");
```

## Fixed example

```mora
// expect: ready
Console.WriteLine("ready");
```
