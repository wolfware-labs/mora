# MR0010: a numeric literal does not fit its type

The literal's value is outside the range of its type: an integer larger than `ulong.MaxValue`, an integer that does not fit the type its context asks for, or a real number so large that it would become infinity. Mora rejects it when it compiles, so the program never runs with a value that silently wrapped or saturated.

The target type decides what fits: `let x: float = 1.5;` compiles, so a real literal that fits a `double` but not a `float` is reported here when a `float` is expected. Use a wider type, or a smaller value.

## Failing example

```mora
// error: MR0010
let big = 18446744073709551616;
Console.WriteLine(big);
```

## Fixed example

```mora
// expect: 18446744073709551615
let big = 18446744073709551615;
Console.WriteLine(big);
```
