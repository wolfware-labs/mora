# MR0011: the C# `\x` escape in a string or character literal

`\x` followed by one to four hexadecimal digits is a C# escape. Its length depends on the characters after it, so `"\x41BC"` is one character, not `A` followed by `BC`, and adding text after an escape can change its meaning. Mora does not have it.

## Coming from C#

Write the code point with `\u{...}`, which has explicit braces: `"\u{41}BC"` is `ABC`. `\u` with exactly four digits also works, as in C#.

## Failing example

```mora
// error: MR0011
Console.WriteLine("\x41");
```

## Fixed example

```mora
// expect: A
Console.WriteLine("\u{41}");
```
