# MR0012: a string, character literal, interpolated string or block comment is not closed

A string, character literal, raw string, interpolated string or block comment starts but never ends. A regular string ends at the end of its line, so a missing quote is reported on that line instead of turning the rest of the file into one long string.

For text that spans lines, use a raw string between backticks, which can span lines. A raw string ends at the next run of as many backticks as opened it, so one that is not closed runs to the end of the file.

## Failing example

```mora
// error: MR0012
let greeting = "Hello;
Console.WriteLine(greeting);
```

## Fixed example

```mora
// expect: Hello
let greeting = "Hello";
Console.WriteLine(greeting);
```
