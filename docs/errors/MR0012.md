# MR0012: a string, character literal, interpolated string or block comment is not closed

A string, character literal, interpolated string or block comment starts but never ends. A regular string ends at the end of its line, so a missing quote is reported on that line instead of turning the rest of the file into one long string.

## Coming from C#

C# reports the same mistakes (CS1010 for a line break inside a string, CS1035 for an unclosed comment). For text that spans lines, use a verbatim string `@"..."` or a raw string `"""..."""`, as in C#.

## Failing example

```mora
// error: MR0012
let greeting = "Hello;
Console.WriteLine(greeting);
```

## Fixed example

```mora
// expect: Hello
let greeting = "Hello";
Console.WriteLine(greeting);
```
