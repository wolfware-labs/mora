# MR0013: an unknown or malformed escape sequence

A backslash in a regular string or character literal must start one of the escapes of §3.5. `\q` means nothing, `\u` takes exactly four hexadecimal digits and `\u{...}` one to six, and a surrogate such as `\uD834` is not a character, because a Mora `char` is a Unicode scalar value.

## Coming from C#

C# also rejects unknown escapes (CS1009), but it accepts surrogate halves in `\u` because its strings are UTF-16. Mora strings are UTF-8, so write the whole code point: `\u{1D11E}` instead of `\uD834\uDD1E`.

## Failing example

```mora
// error: MR0013
Console.WriteLine("\uD834\uDD1E");
```

## Fixed example

```mora
// expect: 𝄞
Console.WriteLine("\u{1D11E}");
```
