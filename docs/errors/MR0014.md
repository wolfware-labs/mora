# MR0014: a malformed numeric literal

The characters of a numeric literal do not form a number: `0x` or `0b` with no digits, a `_` separator that is not between two digits, a suffix Mora does not know, or `m`, which is reserved for a `decimal` type that Mora does not have yet.

## Coming from C#

C# 7 allows a separator right after the prefix, as in `0x_FF`; Mora requires `_` between two digits, as in `0xF_F`. `decimal` and its `m` suffix are not in Mora yet (OQ-12). For money, count the smallest unit in an integer, such as cents.

## Failing example

```mora
// error: MR0014
let price = 19.99m;
Console.WriteLine(price);
```

## Fixed example

```mora
// expect: 1999
let cents = 1999;
Console.WriteLine(cents);
```
