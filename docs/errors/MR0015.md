# MR0015: a character literal that is empty or holds more than one character

A character literal holds exactly one Unicode scalar value. `''` holds none and `'ab'` holds two. Text that is more than one character, such as a letter with a separate combining accent, which is two scalar values, needs a string.

## Coming from C#

C# reports the same mistakes (CS1012, CS1011). One difference runs the other way: `'𝄞'` is an error in C# because it takes two UTF-16 units, and in Mora it is one `char`.

## Failing example

```mora
// error: MR0015
let letter = 'ab';
Console.WriteLine(letter);
```

## Fixed example

```mora
// expect: a
let letter = 'a';
Console.WriteLine(letter);
```
