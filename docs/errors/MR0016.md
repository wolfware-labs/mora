# MR0016: a raw or interpolated string breaks its delimiter, brace or indentation rules

An interpolated or raw string breaks one of its delimiter rules. In an interpolated string, a `}` in the text is written `}}`, and more than one `$` needs a raw string. In an interpolated raw string, braces in the text are written in runs shorter than the hole delimiters. A raw string that spans lines starts its content on the line after the opening backticks and ends it on the line before the closing backticks, and every content line starts with the closing backticks' indentation, which the value leaves out.

The compiler reports the problem on the delimiter or the line that breaks the rule.

## Failing example

```mora
// error: MR0016
let name = "Mora";
Console.WriteLine($"{name} uses } for blocks");
```

## Fixed example

```mora
// expect: Mora uses } for blocks
let name = "Mora";
Console.WriteLine($"{name} uses }} for blocks");
```
