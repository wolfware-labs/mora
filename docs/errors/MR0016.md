# MR0016: a raw or interpolated string breaks its quote, brace or indentation rules

An interpolated or raw string breaks one of its delimiter rules. In an interpolated string, a `}` in the text is written `}}`, and more than one `$` needs a raw string. In a raw string, the closing quotes match the opening ones, a multi-line raw string starts its content on the line after the opening quotes and ends it on the line before the closing quotes, and every content line starts with the closing quotes' indentation, which the value leaves out.

The compiler reports the problem on the delimiter or the line that breaks the rule.

## Failing example

```mora
// error: MR0016
let name = "Mora";
Console.WriteLine($"{name} uses } for blocks");
```

## Fixed example

```mora
// expect: Mora uses } for blocks
let name = "Mora";
Console.WriteLine($"{name} uses }} for blocks");
```
