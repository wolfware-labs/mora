# MR0017: a character that cannot start a token

Outside strings, comments and character literals, Mora source is made of identifiers, numbers, operators, punctuation and whitespace. A backtick, a non-breaking space or a curly quote cannot start any of them.

## Coming from C#

C# reports the same problem (CS1056). It usually comes from code pasted out of a document or a chat window that replaced `"` with `“` and `”`, or a space with a non-breaking space.

## Failing example

```mora
// error: MR0017
Console.WriteLine(“Hello”);
```

## Fixed example

```mora
// expect: Hello
Console.WriteLine("Hello");
```
