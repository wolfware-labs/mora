# MR0018: a `"""` raw string or an `@"..."` verbatim string

A string is written between `"""` quotes or as an `@"..."` verbatim string, with or without `$` for interpolation. Mora writes text without escapes in one form only: a raw string between backticks. The compiler reads the string as written, so the rest of the file is still checked.

Put the text between backticks, as in `` `C:\temp\file.txt` ``. In a verbatim string, `""` stands for one quote; between backticks, a quote is just a quote. When the text holds backticks, use more backticks around it than the longest run inside. A multi-line `"""` string keeps its layout: the lines between the backticks, less the indentation of the closing ones. Keep `$` or `$$` in front for holes. The compiler offers this rewrite as a fix.

## Failing example

```mora
// error: MR0018
let path = @"C:\temp\""quoted"".txt";
Console.WriteLine(path);
```

## Fixed example

```mora
// expect: C:\temp\"quoted".txt
let path = `C:\temp\"quoted".txt`;
Console.WriteLine(path);
```
