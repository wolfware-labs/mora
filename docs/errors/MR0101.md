# MR0101: `try`, `catch`, `finally` or `throw`: Mora has no exceptions

The code uses `try`, `catch`, `finally` or `throw`. Mora has no exceptions: a function that can fail says so in its return type, so a caller cannot forget to handle the failure. A bug that leaves the program in a broken state panics instead, and a panic is not caught.

A function that can fail returns `Result<T, E>`. The caller handles both cases with `switch` or `is`, or passes the error up with `?`. Cleanup that a `finally` block would do belongs in a destructor, which runs when the owner goes out of scope.

## Failing example

```mora
// error: MR0101
Half(n: int): int
{
    if (n % 2 != 0) { throw new ArgumentException("odd"); }
    return n / 2;
}
Console.WriteLine(Half(4));
```

## Fixed example

```mora
// expect: 2
Half(n: int): Result<int, string>
{
    if (n % 2 != 0) { return Err("odd"); }
    return n / 2;
}
Console.WriteLine(Half(4).Expect("4 is even"));
```
