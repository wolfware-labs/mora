# MR0102: `object` or `dynamic`: there is no universal base type

The code names `object` or `dynamic` as a type. Mora has no type that every value converts to: a value's type is always known at compile time, so there is no boxing and no member lookup at run time.

Write a generic parameter when the code works for any type, or an interface when it needs some operations from each type. A union lists a fixed set of alternatives.

## Failing example

```mora
// error: MR0102
let value: object = 42;
Console.WriteLine(value);
```

## Fixed example

```mora
// expect: 42
Show<T>(value: T) where T : IDisplay
{
    Console.WriteLine(value);
}
Show(42);
```
