# MR0103: `typeof`: there is no runtime reflection

The code uses `typeof`. Mora keeps no type information at run time, so there is no `Type` object to get and nothing to inspect through it.

Use `nameof` for a name, a generic constraint to require an operation, or a macro (§9) to generate code from a declaration at compile time.

## Failing example

```mora
// error: MR0103
Console.WriteLine(typeof(List<int>).Name);
```

## Fixed example

```mora
// expect: List
Console.WriteLine(nameof(List<int>));
```
