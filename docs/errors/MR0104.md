# MR0104: `lock` or `volatile`

The code uses `lock` or `volatile`. Mora does not lock on arbitrary objects: shared data lives inside a type that owns the lock or the atomic access, so the data cannot be reached without it.

Shared data belongs inside `Mutex<T>`, which holds the data it protects, or `Atomic<T>` for a single value (post-MVP, §12.6). Until those exist, keep the data on one thread.

## Failing example

```mora
// error: MR0104
let items: List<int> = new();
lock (items) { items.Add(1); }
Console.WriteLine(items.Count);
```

## Fixed example

```mora
// expect: 1
let items: List<int> = new();
items.Add(1);
Console.WriteLine(items.Count);
```
