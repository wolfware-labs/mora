# MR0105: `delegate` or `event`

The code declares a delegate type, an anonymous `delegate` method or an `event`. Mora has function types and closures instead of delegates, and `Signal<T>` instead of events.

Declare a parameter or field as `Func<A, R>` or `Action<A>` instead of a named delegate type, and pass a lambda instead of an anonymous `delegate`. For an event, expose a `Signal<T>`: handlers `Subscribe` to it and get a subscription that unsubscribes when it is dropped, so a forgotten handler cannot keep its target alive.

## Failing example

```mora
// error: MR0105
delegate int Transform(int x);
Apply(f: Transform, x: int): int => f(x);
Console.WriteLine(Apply(x => x * 2, 21));
```

## Fixed example

```mora
// expect: 42
Apply(f: Func<int, int>, x: int): int => f(x);
Console.WriteLine(Apply(x => x * 2, 21));
```
