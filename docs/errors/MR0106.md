# MR0106: `goto`

The code uses `goto`. Mora does not support it, including `goto case` in a `switch`.

Leave nested loops with `break` or `continue`, or move them into a function and `return` from it. Share code between `switch` arms by calling a function from each.

## Failing example

```mora
// error: MR0106
for (var i = 0; i < 10; i++)
{
    if (i == 3) { goto done; }
}
done:
Console.WriteLine("done");
```

## Fixed example

```mora
// expect: 3
FirstMatch(): int
{
    for (var i = 0; i < 10; i++)
    {
        if (i == 3) { return i; }
    }
    return -1;
}
Console.WriteLine(FirstMatch());
```
