# MR0107: `fixed` or `unsafe`

The code uses `unsafe` or `fixed`. Mora has no unsafe code in the MVP: every program is memory safe, and the compiler checks every reference (OQ-11).

Use spans and arrays, which are checked and fast, and declare native functions with `extern` (§13.9).

## Failing example

```mora
// error: MR0107
unsafe
{
    let x: int = 5;
    Console.WriteLine(x);
}
```

## Fixed example

```mora
// expect: 5
let x: int = 5;
Console.WriteLine(x);
```
