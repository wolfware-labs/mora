# MR0108: class inheritance keywords such as `virtual`, `override` or `base`

The code uses `abstract`, `virtual`, `override`, `sealed`, `protected` or `base`. Mora has no class inheritance in the MVP (OQ-4): every type is sealed, so a call always goes to the member the type declares.

Put the shared behaviour in an interface with default methods, and implement the interface in each type. `abstract` stays allowed on `static abstract` interface members.

## Failing example

```mora
// error: MR0108
abstract class Shape
{
    public abstract Area(): double;
}
class Square : Shape
{
    public override Area(): double => 4;
}
Console.WriteLine(new Square().Area());
```

## Fixed example

```mora
// expect: 4
interface IShape
{
    Area(): double;
}
class Square : IShape
{
    public Area(): double => 4;
}
Console.WriteLine(new Square().Area());
```
