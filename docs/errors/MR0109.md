# MR0109: `checked(...)` or `unchecked(...)`

The code uses a `checked` or `unchecked` expression or block. Mora sets overflow checking for the whole build instead of per expression.

Arithmetic overflow panics in debug builds and wraps in release builds, unless the profile sets `overflow-checks` (§17.2). When wrapping is what the code means, say so with the wrapping operators `+%`, `-%` and `*%`, which wrap in every build.

## Failing example

```mora
// error: MR0109
let a: int = int.MaxValue;
Console.WriteLine(unchecked(a + 1));
```

## Fixed example

```mora
// expect: -2147483648
let a: int = int.MaxValue;
Console.WriteLine(a +% 1);
```
