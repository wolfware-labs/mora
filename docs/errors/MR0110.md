# MR0110: a token that the grammar does not allow where it appears

The parser found a token that cannot come next, or did not find one that must. The message names what it expected, such as `` expected `;` `` or `expected a member`. The parser marks the spot and continues at the next statement, member or declaration, so one mistake does not hide the errors after it.

## Coming from C#

C# reports the same mistakes with codes such as CS1002 (`; expected`) and CS1519 (invalid token in a member declaration). Constructs that C# allows and Mora replaces, such as `try`, block-scoped namespaces or primary constructors, have their own codes with a hint instead of this one.

## Failing example

```mora
// error: MR0110
let total = 1 + 2
Console.WriteLine(total);
```

## Fixed example

```mora
// expect: 3
let total = 1 + 2;
Console.WriteLine(total);
```
