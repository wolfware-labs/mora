# MR0120: a block-scoped namespace declaration

The file declares a namespace with braces, `namespace Name { ... }`. A Mora file has at most one namespace, and it is file-scoped: `namespace Name;` before the declarations. The fix rewrites the block form.

Write `namespace Name;` before the declarations. The fix does this: it puts `;` after the name and removes the braces.

## Failing example

```mora
// error: MR0120
namespace Greetings
{
    static class Hello
    {
        public static Text: string => "hello";
    }
}
Console.WriteLine(Hello.Text);
```

## Fixed example

```mora
// expect: hello
namespace Greetings;

static class Hello
{
    public static Text: string => "hello";
}
Console.WriteLine(Hello.Text);
```
