# MR0121: a folder under `src/` does not give a namespace name, or two folders give the same one

Every folder under `src/` is a namespace, named by the folder's name in PascalCase: `src/http-client/` is the namespace `HttpClient` inside the project's root namespace. A folder whose name does not give an identifier, such as `src/2d/`, cannot be named from code. Two sibling folders that give the same name, such as `src/http-client/` and `src/HttpClient/`, would put their files in one namespace without saying so.

Rename the folder so that its name starts with a letter, or merge the two folders into one.

## Failing example

```mora
// error: MR0121
//@ file src/Program.mr
Console.WriteLine("ready");
//@ file src/2d/Square.mr
internal class Square {
}
```

## Fixed example

```mora
// expect: ready
//@ file src/Program.mr
Console.WriteLine("ready");
//@ file src/shapes-2d/Square.mr
internal class Square {
}
```
