# MR0121: `using` as a disposal statement

The code uses `using (...)` or `using var` to dispose of a value. Mora has no `IDisposable` pattern: a value's destructor runs when its owner goes out of scope, so cleanup happens without asking for it.

Declare the value without `using`. Its destructor (`~TypeName()`) runs at the end of the scope, or, if the value moves somewhere that lives longer, at the end of that place's scope (§10.8). `using` stays the keyword of `using` directives.

## Failing example

```mora
// error: MR0121
class Log
{
    public void Write(string text) { Console.WriteLine(text); }
}
using (var log = new Log()) { log.Write("saved"); }
```

## Fixed example

```mora
// expect: saved
class Log
{
    public void Write(string text) { Console.WriteLine(text); }
}
let log = new Log();
log.Write("saved");
```
