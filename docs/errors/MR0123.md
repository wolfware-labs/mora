# MR0123: a signature mentions a type less visible than the member

A member's signature names a type that some of the member's callers cannot see. Code that can call the method or read the field could not name the type of a parameter, a result or the field itself, so it could not declare a local of that type or write a function that passes the value on.

Make the type at least as visible as the member, or make the member less visible. A member's visibility is never wider than its type's, so a `public` member of a type without a visibility modifier may mention any type visible in the folder.

## Failing example

```mora
// error: MR0123
//@ file src/Program.mr
Console.WriteLine(Store.Count(new Store.Secret { Value = 3 }));
//@ file src/Store/Secret.mr
struct Secret {
    public Value: int;
}

internal Count(secret: Secret): int {
    return secret.Value;
}
```

## Fixed example

```mora
// expect: 3
//@ file src/Program.mr
Console.WriteLine(Store.Count(new Store.Secret { Value = 3 }));
//@ file src/Store/Secret.mr
internal struct Secret {
    public Value: int;
}

internal Count(secret: Secret): int {
    return secret.Value;
}
```
