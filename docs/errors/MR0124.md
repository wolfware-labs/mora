# MR0124: both top-level statements and `Main`, or more than one `Main`

An app starts in one place: the top-level statements of its entry file, or one function named `Main`. With both, or with two `Main` functions, the compiler cannot tell where the program starts.

Keep one entry point: move the statements into `Main`, or remove the extra `Main`. A `Main` that is an ordinary method of an object, not `static`, is not an entry point and can stay.

## Failing example

```mora
// error: MR0124
Console.WriteLine("starting");

Main() {
    Console.WriteLine("hello");
}
```

## Fixed example

```mora
// expect: starting
// expect: hello
Main() {
    Console.WriteLine("starting");
    Console.WriteLine("hello");
}
```
