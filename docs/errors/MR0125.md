# MR0125: top-level statements in a library, or outside an app's entry file

Top-level statements form the body of the program's generated `Main`, so they belong in one file: the entry file of an app, `src/Program.mr` unless the manifest names another. A library has no entry point, and in an app the statements of a second file would have no defined order relative to the first.

Move the statements into a function, and call it from the entry file.

## Failing example

```mora
// error: MR0125
//@ file src/Program.mr
Console.WriteLine("hello");
//@ file src/Setup.mr
Console.WriteLine("setting up");
```

## Fixed example

```mora
// expect: setting up
// expect: hello
//@ file src/Program.mr
Setup();
Console.WriteLine("hello");
//@ file src/Setup.mr
internal Setup() {
    Console.WriteLine("setting up");
}
```
