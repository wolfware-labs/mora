# MR0127: a name that does not resolve

No declaration that the code can reach has this name. The compiler looks in the enclosing namespaces, the project's root namespace, its dependencies, `Std`, the namespaces that `using` directives open, and the prelude, and none of them declares it. The usual causes are a misspelled name, a missing `using` directive, or a path that names a folder that does not exist.

Correct the spelling, or write the path from a namespace the code can reach.

## Failing example

```mora
// error: MR0127
//@ file src/Program.mr
using App.Stores;

Console.WriteLine(Count());
//@ file src/Store/Users.mr
internal Count(): int {
    return 3;
}
```

## Fixed example

```mora
// expect: 3
//@ file src/Program.mr
using App.Store;

Console.WriteLine(Count());
//@ file src/Store/Users.mr
internal Count(): int {
    return 3;
}
```
