# MR0128: a name that resolves to more than one declaration

Two declarations with this name are equally close to the code that uses it, so the compiler cannot choose. This happens when two types in one namespace share a name, when a type has the name of a folder beside it, or when two `using` directives open namespaces that both declare it. Functions are the exception: functions with one name are overloads, chosen by their arguments.

Rename one of the declarations, or write more of the path to say which one you mean.

## Failing example

```mora
// error: MR0128
//@ file src/Program.mr
using static App.Store.Item;
//@ file src/Store/Item.mr
internal class Item {
}
//@ file src/Store/Order.mr
internal struct Item {
}
```

## Fixed example

```mora
// expect: done
//@ file src/Program.mr
using static App.Store.Item;

Console.WriteLine("done");
//@ file src/Store/Item.mr
internal class Item {
}
//@ file src/Store/Order.mr
internal struct OrderItem {
}
```
