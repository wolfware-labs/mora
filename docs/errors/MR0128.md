# MR0128: a primary constructor on a class or struct

A class or struct declaration has a parameter list after its name, as in C# 12. Mora types have no primary constructors: fields and constructors are declared in the body, so every field has one declaration.

Declare the fields and a constructor that assigns them. A record (§6.5) still takes a parameter list, because its parameters become its properties.

## Failing example

```mora
// error: MR0128
class Point(int x, int y)
{
    public int Sum => x + y;
}
Console.WriteLine(new Point(1, 2).Sum);
```

## Fixed example

```mora
// expect: 3
class Point
{
    int x;
    int y;
    public Point(int x, int y) { this.x = x; this.y = y; }
    public int Sum => x + y;
}
Console.WriteLine(new Point(1, 2).Sum);
```
