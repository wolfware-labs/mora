# MR0128: a primary constructor on a class

A class declaration has a parameter list after its name, as in C# 12. A class has identity and usually state that changes, so Mora declares its fields and constructors in the body, where every field has one declaration with its mutability.

Declare the fields, and either a constructor that assigns them or none at all, so the class is created memberwise with `new Point { X = 1, Y = 2 }` (§6.9). A struct may take a parameter list: `struct Point(int X, int Y);` declares a positional struct whose parameters are its fields (§6.5).

## Failing example

```mora
// error: MR0128
class Point(int x, int y)
{
    public int Sum => x + y;
}
Console.WriteLine(new Point(1, 2).Sum);
```

## Fixed example

```mora
// expect: 3
class Point
{
    int x;
    int y;
    public Point(int x, int y) { this.x = x; this.y = y; }
    public int Sum => x + y;
}
Console.WriteLine(new Point(1, 2).Sum);
```
