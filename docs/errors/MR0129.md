# MR0129: `null`, which Mora writes as `none`

The code uses `null`. Mora has no null references: a plain type such as `User` always holds a value, and only an option type `User?` can be empty. The empty value of an option is written `none`, so the word `null` is reserved and reported, with a fix that replaces it.

Write `none` wherever an option has no value: `let u: User? = none;`, `if (u is none)`, `none => ...` in a `switch`. The operators `??` and `?.` work the same way.

## Failing example

```mora
// error: MR0129
let name: string? = null;
Console.WriteLine(name ?? "anonymous");
```

## Fixed example

```mora
// expect: anonymous
let name: string? = none;
Console.WriteLine(name ?? "anonymous");
```
