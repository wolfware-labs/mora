# MR0129: a declaration that is not visible from here

The name resolves, but the declaration is hidden from this code. A declaration without a visibility modifier is visible only in its folder, so an unmarked type in `src/Store/` cannot be used from a file in `src/`. A `file` declaration is visible only in its file, a `private` member only inside its type, and only `public` declarations reach other projects. The error names the folder that declares the item and the folder that uses it.

Mark the declaration `internal` to use it anywhere in the project, or `public` to use it from other projects. The fix does this for you.

## Failing example

```mora
// error: MR0129
//@ file src/Program.mr
using App.Store.UserStore;
//@ file src/Store/UserStore.mr
class UserStore {
}
```

## Fixed example

```mora
// expect: done
//@ file src/Program.mr
using App.Store.UserStore;

Console.WriteLine("done");
//@ file src/Store/UserStore.mr
internal class UserStore {
}
```
