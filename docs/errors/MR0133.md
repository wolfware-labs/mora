# MR0133: `record`, which Mora writes as `struct`

A type is declared with `record`, `record struct` or `record class`, as in C#. Mora has no records. A record's data has no identity, which is what a struct means, and a positional struct gives the rest: its parameters are public read-only fields, and it gets a constructor, deconstruction, equality, `with` and printing (§6.5).

Write `struct` in place of `record`, `record struct` or `record class`. The compiler offers this as a fix.

## Failing example

```mora
// error: MR0133
record User(Id: int, Name: string);
let ada = new User(1, "Ada");
Console.WriteLine(ada.Name);
```

## Fixed example

```mora
// expect: Ada
struct User(Id: int, Name: string);
let ada = new User(1, "Ada");
Console.WriteLine(ada.Name);
```
