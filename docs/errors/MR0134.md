# MR0134: `required` or `init`, which memberwise creation replaces

A field is marked `required`, or a property has an `init` accessor, as in C#. Mora does not need either. A field without an initializer is already required: every way of creating the value must set it. A read-only field or property can already be set only when the value is created, with `new T { X = ... }` or a constructor (§6.9).

Remove `required`. Remove the `init` accessor, so `{ get; init; }` becomes `{ get; }`; when `init` is the only accessor, write `get` in its place. The compiler offers these as fixes.

## Failing example

```mora
// error: MR0134
class Server
{
    public required Host: string;
    public Port: int { get; init; }
}
let s = new Server { Host = "localhost", Port = 8080 };
Console.WriteLine($"{s.Host}:{s.Port}");
```

## Fixed example

```mora
// expect: localhost:8080
class Server
{
    public Host: string;
    public Port: int { get; }
}
let s = new Server { Host = "localhost", Port = 8080 };
Console.WriteLine($"{s.Host}:{s.Port}");
```
