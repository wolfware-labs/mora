# MR0135: a declaration that puts the type before the name

A field, property, method, parameter, local, lambda parameter, local function, union case field or positional parameter is written with its type first, as C# writes it. Mora declares every one of them the same way: the name first, then a colon and the type. A method's return type goes after its parameter list.

Move the type after the name and a colon. `int count = 3;` becomes `var count: int = 3;`, or `let count: int = 3;` when the value never changes. A parameter `string name` becomes `name: string`, and `int Twice(int x)` becomes `Twice(x: int): int`. A method that returns nothing has no return type, so `void` goes away. The compiler offers this rewrite as a fix.

## Failing example

```mora
// error: MR0135
int count = 3;
Console.WriteLine(count);
```

## Fixed example

```mora
// expect: 3
let count: int = 3;
Console.WriteLine(count);
```
