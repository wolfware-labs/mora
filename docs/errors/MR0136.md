# MR0136: `void` as a type

A function declares `: void` as its return type. A function that returns nothing returns the unit type `()`, and Mora says so by leaving the return type out. `void` is a reserved word, but it is not a type.

Remove `: void`, so the parameter list is followed by the body. The compiler offers this as a fix.

## Failing example

```mora
// error: MR0136
Greet(name: string): void
{
    Console.WriteLine($"Hello, {name}!");
}
Greet("Ada");
```

## Fixed example

```mora
// expect: Hello, Ada!
Greet(name: string)
{
    Console.WriteLine($"Hello, {name}!");
}
Greet("Ada");
```
