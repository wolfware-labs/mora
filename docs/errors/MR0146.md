# MR0146: two members of one type with the same name, other than overloaded methods

A type declares two members with one name, and at least one of them is not a method. A use of the name inside or outside the type could then mean either member, so the compiler cannot tell which one the code reads or calls.

Rename one of the members. Methods may share a name with each other when their parameters differ, because a call chooses among them by its arguments.

## Failing example

```mora
// error: MR0146
public struct User {
    public Name: string;
    public Address: string;

    public struct Address {
        public Line: string;
    }
}
```

## Fixed example

```mora
// expect: Ada
public struct User {
    public Name: string;
    public Home: Address;

    public struct Address {
        public Line: string;
    }
}

let user = new User { Name = "Ada", Home = new User.Address { Line = "1 Main St" } };
Console.WriteLine(user.Name);
```
