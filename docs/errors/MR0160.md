# MR0160: the null-forgiving operator `x!`

The code uses the postfix `!` operator to say that a value is not `null`. Mora checks optional types for real, so this claim has to be a check: the code says what happens when the value is missing.

Use `.Value`, which panics when the value is missing, or `.Expect("why it is set")`, which panics with that message. Often neither is needed: after `if (x != null)`, flow narrowing (§5.6) makes `x` non-optional.

## Failing example

```mora
// error: MR0160
string? name = "Ada";
Console.WriteLine(name!.Length);
```

## Fixed example

```mora
// expect: 3
string? name = "Ada";
Console.WriteLine(name.Expect("name is set above").Length);
```
